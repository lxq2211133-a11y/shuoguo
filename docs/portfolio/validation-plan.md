# 硕果研习｜首轮用户验证计划

> 本文件是执行计划与记录模板，不包含真实访谈结果。

## 目标与招募

目标：验证目标考生是否需要“院校驱动的每日训练”，并找出第一条带背流程中的理解和操作障碍。

建议招募 5 位正在备考或最近一年备考产品设计／工业设计研究生考试的人。记录目标院校、备考阶段、理论与快题的主要困难；不要只找熟悉该原型的朋友。未经同意，不保存姓名、联系方式或原始录音。

## 访谈问题（先问现状，再展示原型）

1. 你上周如何决定每天学什么？请回忆一次具体安排。
2. 理论、快题和院校信息分别放在哪里？最近一次找资料花了多久？
3. 做完一道题或一张快题后，你如何知道下一步该练什么？
4. 你现在用什么方法安排复习？哪一步最容易中断？
5. 看到“院校风格”和“AI 评图”时，你会相信到什么程度？需要什么依据？

## 可用性任务

测试时不提示按钮位置，让参与者边操作边说出想法。

| 任务 | 观察点 |
|---|---|
| 选定自己的目标院校，并说出资料中哪些信息已核实 | 来源标注是否被看到、是否误把推断当事实 |
| 找到今天该做的练习，完成一张带背卡片 | 是否能找到入口、是否理解自评选项 |
| 返回首页，说明自己的记录发生了什么变化 | 是否看懂已复习与待复习状态 |
| 打开示例评图，判断这个分数是否来自真实图片分析 | 模拟能力边界是否清楚 |

每项记录：是否独立完成、用时、卡住位置、原话、是否需要提示。结束后问“最有用的一点是什么”“最不可信的一点是什么”“明天会因为什么再打开”。
