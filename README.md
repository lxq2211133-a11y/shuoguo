# -# 硕果 Shuoguo

### AI-Powered Design Learning & Critique Platform

**让设计学习从经验判断走向结构化、可解释的智能反馈。**

硕果（Shuoguo）是一款面向设计考研与设计手绘训练场景的 AI 学习平台。项目围绕设计作品评估、专业知识学习和个性化反馈展开，探索多模态 AI、专家评分标准（Rubric）与 RAG 检索技术在设计教育中的应用。

---

## 01. 项目背景

在设计考研和设计手绘训练过程中，学生通常面临三个问题：

- **反馈不够及时：** 传统评图依赖教师或专业人员，难以持续获得反馈。
- **评价标准不统一：** 不同评价者的经验和判断存在差异，学生难以理解作品具体问题。
- **学习缺乏针对性：** 学生知道作品存在不足，却不一定清楚如何改进。

硕果希望通过 AI 技术，将专家经验、设计评价标准与案例知识结合起来，为学生提供更具结构性和可解释性的学习反馈。

## 02. 核心产品能力

### AI 智能评图

围绕设计手绘与考研快题场景，对学生提交的作品进行多维度分析。

评价体系以结构化 Rubric 为基础，关注作品质量、设计表达、方案完整性及具体问题，并提供改进建议。

### 专家案例知识库

建立具有不同质量等级的设计案例库。

当前项目包含 13 组原创评图案例，配套案例文本、评价信息和向量数据，用于支持案例参考与检索。

### 多模态 AI

结合视觉模型与文本模型，探索从设计图片理解到专业反馈生成的完整流程。

### RAG 检索增强

通过案例文本、Embedding 和向量检索，为 AI 评图提供相关参考案例，提升反馈的针对性与可追溯性。

## 03. RAG 技术流程

```text
设计作品上传
      |
      v
多模态视觉理解
      |
      v
提取作品特征与问题
      |
      v
构建检索查询
      |
      v
专家案例向量检索
      |
      v
召回相关参考案例
      |
      v
结合 Rubric 评分标准
      |
      v
生成结构化评图报告
      |
      v
学生根据反馈进行修改
```

### 案例库数据结构

案例数据围绕以下信息组织：

- 案例 ID
- 作品图片路径
- 作品标题
- 质量等级
- 设计标签
- 专家点评
- 作品优点
- 存在问题
- 改进建议
- Embedding 向量

项目当前提供原创案例图片、案例文本和向量数据。

## 05. 本地运行

### 环境要求

- Node.js（建议使用 LTS 版本）
- npm

### 安装依赖

```bash
npm ci
```

### 配置环境变量

复制 `.env.example` 为 `.env.local`，根据实际使用的 AI 服务配置 API Key。

注意：真实 API Key 应保存在本地环境变量或服务端配置中，不要提交到公开仓库。

### 启动开发环境

```bash
npm run dev
```

### 构建项目

```bash
npm run build
```

具体 AI 功能还需要配置对应的模型服务及环境变量。

## 06. 项目特色

- 将设计评价标准转化为结构化 Rubric。
- 使用原创案例构建设计评图知识库。
- 探索多模态视觉理解与 RAG 的结合。
- 通过案例检索为 AI 反馈提供参考依据。
- 关注从作品评价到持续学习的产品闭环。

## 07. 项目定位

**Shuoguo 不只是一个 AI 图片点评工具，而是一次面向设计教育场景的 AI 产品实践。**

项目关注如何将专业知识、专家经验和多模态 AI 能力转化为可落地的产品体验。
